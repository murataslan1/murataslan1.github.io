VAKA 2 · vercel/ai#14019

Yalan Hata

Vercel AI SDK'da tool exception'larının tipi (TypeError, RangeError) silinip model'e gidiyordu.

Model "API crashed" görüyor — failure mı, normal string return mü? Anlayamıyor.

- error.message      // "API crashed"
+ error.toString()    // "TypeError: API crashed"
Bir kelime fark. Agent için yer ile gök.

Vercel AI maintainer'ları merge etti → ek test case eklendi, contributor olarak listelendim
